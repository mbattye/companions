# Companions · Ἑταῖροι

An Aristotelian curriculum for the modern student, assisted by AI.

Open `index.html`, or run `python3 -m http.server 8000` and visit http://localhost:8000.

See `CLAUDE.md` for how the project is organised and `ROADMAP.md` for what's next.
